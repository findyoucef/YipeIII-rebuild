The sounds for monster deaths for Yipe! III are in this folder.

If you have accidently deleted the sounds in this folder, 
you can download the original set of sounds from:
http://www.yipesoftware.com/monsters/

The main reason these monster sounds are stored in this folder
is so that you can add, delete, and change the sounds for each
monster.

All you have to do is put a .wav sound file into this folder with
the number of the monster that you want the sound to be associated
with.  For instance, if you wanted to replace the generic sound
the bunny makes when it dies, you would put a sound file in this
folder called:  1.wav

You can put in sounds for all 40 monsters if you want.  Although
there are a couple of exceptions.  Some of the monsters share the
same sound.  Here is a list of shared monster sounds:

Monsters number 8, 10 and 11 will always play sound 8.wav
Monsters 21 and 22 will always play 21.wav
Monsters 25, 26 and 27 will always play 25.wav
Monsters 35 and 39 will always play 35.wav
Monsters 38 and 40 will always play 40.wav

So, if you make a sound 10.wav, it will never be played.  To
change the sound for that monster you'd have to change sound
8.wav, which would then also affect monsters 8 and 11.

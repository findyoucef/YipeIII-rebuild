# Map references

When the user identifies a game location by world-map placement, a region label
such as `D4`, local coordinates such as `5,6`, or a nearby landmark, read and use
[locate-map-region](.agents/skills/locate-map-region/SKILL.md) before diagnosing
or changing that location. Resolve it from the map and inspect the relevant area;
do not assume it belongs to the last-discussed biome or the currently open scene.

# Cave remastering

For cave visual remasters or refinements, read and use the repository-local
[remaster-yipe-caves](.agents/skills/remaster-yipe-caves/SKILL.md) skill.
